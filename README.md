# Falman Studio

A small, responsive storefront for Falman Studio. The site is built with plain HTML, CSS, and JavaScript, so it can be hosted on GitHub Pages or any static web host without a build step.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Store features

- Responsive product catalog with category filters
- Shopping bag with quantity controls and browser-local persistence
- Subtotal and complimentary-shipping progress indicator
- Email-based order request with a prefilled item list

This is a front-end demo: it does not collect payment or customer details. Before taking real orders, update the sample catalog and contact email, and connect a trusted checkout/payment provider.
